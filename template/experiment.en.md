# (Title of the experiment)

[日本語](./experiment.md)

This template is copied to `experiments/<name>/experiment.en.md`.
The values of the fields go in `experiment.json` in the same place.
The headings are not changed or reordered.

## Question

A single question, in a form that can be checked.
It is written so that either answer, yes or no, is kept in the record.

## Route

Which of the routes that rule 15 names the experiment goes by.
It is one of joint research, JOSS, a conference presentation or a diamond open access venue.
An experiment without a route is not added.

## Data source and licence

Where the data are, and their licence.
When and where the licence was checked.
That the data hold no personal data, and why.

## Method

What is counted and how it is compared.
The tools used, with their versions.

## Plan fixed in advance

Before the data are seen, the question, the hypotheses, the analysis and the condition for stopping are fixed, with the date.
A change to the plan adds the date and the reason.
The earlier plan is not deleted.

## Code

Where the code is, and how the results are made again.
The seed, if random numbers are used.

## Results

The results of the analysis fixed in the plan come first.
Analyses not in the plan are set apart as such.
If the question could not be answered, that is written too.

## Limits

The limits of the data, the method and the results.
What cannot be said.

## Disclosure

Conflicts of interest, and the use of language models.
